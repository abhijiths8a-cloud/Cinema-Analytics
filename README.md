# Cinema Analytics – Director Filmography & Box Office Tracker

## About the Project
Cinema Analytics is a database management application developed using Python, 
SQLite and Tkinter. It helps manage directors, movies and box office information in one place.

## Technologies Used
- **Python:** Main programming language.
- **SQLite:** Stores and manages the database records.
- **Tkinter:** Creates the graphical user interface (GUI).
- **SQL:** Performs database operations.

## Features
- Add, edit and delete director and movie records.
- Manage box office information.
- View directors' filmographies.
- Display database records through a graphical interface.

## Project Files
- `Untitled20.ipynb` – Python implementation.
- `cinema.db` – SQLite database.
- `DBMS_CE_4.pdf` – Project report.

## How It Works
Python connects to SQLite using the `sqlite3` module. SQL commands manage the records, 
while Tkinter provides a user-friendly interface to interact with the database.
